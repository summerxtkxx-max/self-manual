# 自我说明书 · Self Manual

**当前版本 v1.0.0** · [更新记录](CHANGELOG.md)

**不是测试你是谁，而是陪你把自己一点点想起来。**

这是一个中英双语的 Claude Skill。它不给你贴人格类型，而是像一位会聊天的访谈师，陪你回忆真实发生过的事：哪天晚上回家觉得"今天还挺不错"，哪顿饭到现在还会想起，哪次聚会让你累到不想说话。然后和你一起慢慢写出一本**《我的自我说明书》**：什么让你开心、在哪里最舒服、什么会悄悄耗掉你的电量、怎么休息才算真休息、你擅长什么、和人相处需要什么，以及你还没想明白的自己。

## 它和测试题有什么不一样

- **问经历，不问自评。** 人很难准确概括自己，但很容易想起具体的某一天。每一条都来自你真实过过的日子。
- **你点头才算数。** AI 的解读都标成"推测"，每一条你都可以确认、改写或删掉。
- **存证据，不存标签。** 每条结论都附上依据、反例和把握程度（✅已确认 / 🔸推测 / ❓待探索），说明书会跟着你一起变。
- **知道什么时候该停。** "喜欢吃火锅"记一笔就好，不会被追问五次。值得深聊、你也有兴致的时候，才会往下挖。
- **好玩，但不吵。** 二选一快问快答、填空、盲盒抽题、"我的使用说明书·家电版"……你状态不好的时候，它会自动安静下来。
- **复杂情绪不美化。** 嫉妒、虚荣、矛盾，都被好奇地看见，不会被强行翻译成"其实你只是……"。

## 能用它做什么

| 玩法 | 会发生什么 |
|------|-----------|
| 轻松热身 | 5 个小回忆，约 10 分钟，得到第一版雏形 |
| 深度访谈 | 九个范畴任选：幸福时刻、舒服的环境、饮食、能量与消耗、休息消费与审美、兴趣与优势、关系、价值取舍、迷茫纠结 |
| 导入旧对话 | 把之前和 AI 的长谈或笔记贴进来，整理成初版（旧 AI 的结论只算推测） |
| 每日一问 | 每天一个轻量问题，两分钟答完 |
| 偏好实验室 | 把一个推测变成生活里的小实验，验证后更新说明书 |
| 盲区探测 | 积累够了之后，温和地检查那些看起来互相矛盾的结论 |
| 生活使用指南 | 把说明书变成能用的东西：理想的一周、低能量时怎么恢复、做重大选择时要考虑什么 |

## 安装

1. 下载本仓库里的 `self-manual.skill`（或 `self-manual` 文件夹）。
2. **Claude App（网页 / 桌面端）**：在设置的 Skills 里上传这个文件。
   **Claude Code**：把 `self-manual` 文件夹放进 `~/.claude/skills/`。
3. 新开一个对话，说一句"我想写一本自己的说明书"或者"帮我想想我到底喜欢什么"就能开始。

中英文都可以用，你用什么语言说话，它就用什么语言回。

## 怎么保存说明书

Skill 本身不会在对话之间记住内容。每次聊完，Claude 会给你更新后的说明书，存到备忘录或文档里，下次贴回来就能接着写。

## 试吃一口

> **Claude**：最近三个月，有没有哪天晚上回到家觉得"今天还挺不错"？
> **你**：可能是那个在咖啡店待了一下午的周六吧，其实也没干什么。
> **Claude**：让你舒服的，是那家店本身，还是那天刚好没人找你？
> **你**：……好像是后者。
> **Claude**：那我先放进小口袋，标成推测：🔸 *在"没人需要你回应"的环境里最能回血。* 这么说对吗？要不要换个说法？

## 边界

这是自我探索工具，不是心理咨询或诊断，不会推断健康或心理状况。说明书完全属于你，想删随时删。如果聊到真正难受的事，它会先停下流程陪着你，必要时建议你找信任的人或专业人士聊聊。
