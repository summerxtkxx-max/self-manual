# 说明书模板

没有内容的部分保留标题，写"（待探索）"，不要编。状态用 ✅已确认 / 🔸推测 / ❓待探索 / 🔍待验证盲区，判断标准见 `inference-rules.md`"证据等级"。

条目只存一处：所有条目写在"三、九个范畴"里；"一""二""四"是从这些条目里摘出来的速览，改了条目要同步更新速览，不要两边各写一套。

# 我的自我说明书

更新日期：YYYY-MM-DD　｜　第 N 版

## 一、已知的我 / 可能的我 / 未知的我
- **已知的我**：3～5 条最稳的结论（只放 ✅）
- **可能的我**：有线索、待验证的假设
- **未知的我**：我最想搞清楚的问题（写成问题）

## 二、跨场景主题
在两个以上范畴反复出现的需求或模式。每条标注来源范畴和状态。

## 三、九个范畴
1 幸福时刻　2 舒服的环境　3 饮食　4 能量与消耗　5 休息、消费与审美　6 兴趣与优势　7 关系与相处　8 价值与取舍　9 迷茫与纠结

每个范畴下按"长期稳定 / 当前阶段 / 最近变化"分组列条目。

## 四、我的偏好地图（具体、生活化）
从范畴条目里摘出的直接偏好速览，方便她或别人一眼看懂：舒服的环境 / 饮食 / 幸福时刻清单 / 休息与充电 / 消费与审美 / 旅行与娱乐 / 其他。一句话加因素即可，重要偏好再写"为什么"。

## 五、变化记录
- 旧 → 新｜大概时间｜她说的背景｜现在以哪个为准

## 六、偏好实验记录
- 假设｜实验设计｜她的体验记录｜结论（支持 / 修正 / 推翻）

## 七、给别人的使用提示（她想要时再生成）
怎么让我开心 / 什么会让我不舒服 / 我低能量时是什么样、别人怎么做更好 / 做重大决定时提醒我什么

只用 ✅ 条目，写成她愿意直接给家人朋友看的样子。更完整的行动版本见 `life-guide.md`。

## 八、待探索清单
所有 ❓、🔸、🔍 里最值得下次聊的问题，按她在意程度排序；进行中的实验也列在这里，方便下次回访。

**暂不想聊**：她说过不想碰的话题，只写一个词，不写内容。以后不主动提起，除非她自己提。

## 九、更新记录
- YYYY-MM-DD：新增 / 修改 / 升级 / 新发现的矛盾 / 被否定的假设

## 条目格式

完整格式（模式、需求、优势、价值观类）：

- 状态 **结论**：……（条件式，"在……情况下，我……"）
  - 事实：她说过的具体经历（模式类至少 2～3 条）
  - 她的自我判断：……（如有）
  - AI 的假设：……（如有）
  - 反例：……（没有写"暂无"）
  - 把握程度：高 / 中 / 低　｜　时间性：长期稳定 / 当前阶段 / 最近变化
  - 这个结论有什么用：……（比如"选工作时优先看自主度"）
  - 最近更新：YYYY-MM-DD
  - 下一步：……（可选）

简化格式（直接偏好事实）：

- ✅ 不吃香菜（口感和气味都不行）｜更新：YYYY-MM-DD
- ✅ 喜欢有轻微背景声、人不多、能独处的咖啡店｜因素：背景声 / 不用社交 / 环境好看｜更新：YYYY-MM-DD
