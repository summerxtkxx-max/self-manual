# 玩一玩：小玩法题型

可爱体现在玩法设计上，而不是堆语气词。一次只玩一个，玩完把有料的回答放进小口袋，再决定要不要轻拆或深挖（见 `interviewer.md` 三档深度）。玩法里的回答一样要她确认才写入；她情绪低落时不推玩法。

## 二选一快问快答
连续抛 5～8 组，让她凭直觉选，选完再问最有意思的一两组"为什么"。
- 雨天窝家里 / 雨天出门走走
- 热闹小聚 / 安静独处
- 提前计划好 / 走到哪算哪
- 吃熟悉的老味道 / 试没吃过的新店
- 早起 / 熬夜
- 小而精的房间 / 大而空的房间
- 听别人讲 / 自己讲
- 完成一件事的成就感 / 做事过程里的沉浸感
- 被需要 / 被理解
- 有人陪着发呆 / 一个人发呆
- 靠窗的位置 / 角落的位置
- 一次说清楚 / 慢慢聊明白
- 收到惊喜 / 收到刚好想要的
- 夏天的晚上 / 冬天的早上
- 一个大目标 / 很多小目标
- 被提前通知 / 被临时惊喜

## 填空
- "我最舒服的周六是：____。"
- "每次我 ____，我都会觉得自己活过来了。"
- "我一听到 ____ 就想逃。"
- "我最不愿意承认的小爱好是 ____。"
- "如果有一天完全属于我，我会 ____。"
- "我最近一次觉得'这钱花得值'，是买了 ____。"
- "别人不知道，其实我很怕 ____ 的场合。"
- "只要有 ____，再难熬的一天我也能撑过去。"
- "我以前很喜欢 ____，后来不知道为什么就不碰了。"

## 假设情境
- 明天突然多出一个完全属于你的周六，没人找你，也没有必须完成的事。你会怎么过？（先问大概，再问几点起床、第一件事、中午吃什么、晚上和谁）
- 有人给你一笔钱，必须一周内花完，而且只能花在让你开心的事上，你怎么花？
- 给你一个月完全自由，不用向任何人交代，你会先去哪？
- 你可以把现在生活里的一件事删掉，你删什么？再加一件事，你加什么？
- 你可以回到过去任何一天，重新过一遍（不改变什么，只是再体验一次），你选哪天？
- 你被派去一座陌生城市住一个月，只能带三样东西，你带什么？到了第一天先去哪？

## 盲盒抽题
让她随机抽 1～9 的数字，对应范畴，抽到哪个就从该范畴的 ☀️ 里挑一题（编号见 `start.md` 范畴地图）。抽到不想回答的，可以"换一个"，不问原因。

## 人物对照
- "如果让你描述你最舒服的朋友，用三个词，会是哪三个？"
- "如果你的理想一天是一部电影，它会是什么类型？有什么镜头？"

## 小相册
- "翻翻你手机相册最近三个月，哪几张照片让你有'这天真好'的感觉？"
- "你相册里最多的是什么？它说明你在意什么？"

## 一句话今日
- "今天有一个瞬间你想留住吗？是什么？"
- "今天哪件小事让你有一点点开心？"


## 我的使用说明书·家电版
假装她是一台家电，一起写"产品说明书"的几行，好玩又能带出真实偏好：
- "最佳工作温度"：什么环境下运转最顺？
- "充电方式"：怎么给这台机器回血？
- "故障提示"：快没电时会出现什么信号？（话变少、想吃甜的、不回消息……）
- "请勿"：哪些操作会让它死机？
写完挑一两条最有意思的问"这条有没有一个最近的例子？"

## 时间胶囊
- "给一年前的自己发一条消息，告诉她这一年你发现了自己什么，你会写什么？"
- "如果一年后的你回来看今天的说明书，你猜她会改哪一条？"

## 三个瞬间
- "用三个瞬间介绍你的上一个月：一个开心的、一个累的、一个说不上来的。每个一句话就行。"
- 挑她最有感觉的那个瞬间，用"轻拆"追 1～2 轮。

## 这个 vs 那个：真实版
不是假设选择，而是她真实经历过的两件事放在一起比：
- "最近两个周末，哪个过得更好？差在哪？"
- "最近两顿外卖，哪顿更满足？"
- "这周和上周，哪周更累？"
适合想做对照、又不想聊太深的时候。

## 排行榜
- "你吃过的面，前三名是？"
- "你待过最舒服的三个地方，排个序。"
- "今年最值的三笔小开销。"
排完问"第一名凭什么是第一名？"，往往能拆出因素。

## 反向出题
让她自己出一道"如果有人想了解我，最该问的问题"，你把它改写成一个具体场景题再还给她答。她出的题本身也是线索：她最想被问到什么，往往就是她在意的。适合她有点卡住、想换换节奏的时候。
