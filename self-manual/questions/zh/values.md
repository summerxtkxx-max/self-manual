# 价值与取舍

用法同 joy。从真实的选择和情绪反应里找价值，少用"你看重什么"这种抽象问法；排序类题目问完一定追一个具体例子。

## ☀️ 轻松
- 如果今天可以只做一件事，让你觉得"这一天值了"，会是什么？
- 你最不能忍受别人做什么？
- 你有没有一条"生活小原则"？（比如"不借钱""不熬夜"）
- 你喜欢的人物（真实或虚构）身上，有什么你欣赏的特质？
- 如果钱不是问题，你一定不会放弃的一件事是什么？
- 最近一次你觉得"这事我做得对"，是什么事？
- 最近有没有一条新闻、一个帖子或一件身边的事，让你特别生气？气的是哪一点？
- 你选东西（买东西、选课、选工作）时，最先排除的通常是什么？
- 你最近一次为了一件事愿意早起或熬夜，是什么？
- 有没有一个习惯，你坚持了很久，别人劝也不改？
- 你羡慕过身边谁的生活？羡慕的是哪一部分？

## 🌤️ 进阶
- 回头看你做过的重要选择，当时最看重什么？
- 你最近一次说"不"，是为了什么？
- 稳定、自由、成就、被爱、被尊重、成长，你会怎么给它们排序？
- 你在"想要"和"应该"之间，一般站哪边？
- 你的底线是什么？有没有曾经被碰过的？
- 让你愿意牺牲一些舒适去换的东西是什么？
- 如果必须在"赚得多但不自由"和"赚得少但自由"之间选，你会怎么选？为什么？
- 你对"成功"的定义，这几年有变过吗？
- 你最敬佩的人和你最不想变成的人，分别是什么样的？
- 回想你最近一次很难做的选择，最后让你拍板的那个理由是什么？
- 有没有一个选择，当时别人都不看好，你还是做了？现在怎么看？
- 在你待过的学校、公司或团体里，哪种做事方式让你最不能接受？
- 你身边有没有一个人，你虽然不认同他的选择，但很佩服他？佩服的是什么？
- 如果你接下来一年只能在"学东西""赚钱""陪重要的人""去体验"里重点选一个，你选哪个？现在的生活是这样排的吗？
- 这几年里，有没有一件你以前很看重、现在没那么在乎的事？是什么让它变了？
- 你会为了什么愿意让别人失望？

## 🌙 深夜档
- 你的价值观里，有哪些是你自己选的，哪些是别人给你的？
- 你有没有为了某个价值观付出过代价？值得吗？
- 如果十年后的你回头看现在，最不想看到你为了什么放弃了什么？
- 你对"我想成为什么样的人"的答案，和"别人希望我成为什么样的人"有多重合？
- 有没有一次，你做了一个违背自己原则的决定？当时是什么让你那么做？只说你愿意说的部分。
- 你有没有一直在努力证明什么？想证明给谁看？
- 如果你的人生最后只剩一句话被人记住，你希望是什么？
- 这题可以跳过：有没有一个"应该"，你一直背着，但其实很想放下？
