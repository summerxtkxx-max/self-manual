# 我的生活使用指南

说明书负责认识自己，生活指南负责把认识转化为行动。

## 什么时候提供

- 已确认条目大约 8～10 条以上，并覆盖了相关范畴；
- 她表示想要，或正在面对一个选择（换工作、搬家、安排一周）。
素材不够的章节，不硬写，写"这部分素材还不够，建议先补这几个问题：……"

生活指南是说明书之外单独的一份文档，和说明书一样提醒她保存；说明书的"给别人的使用提示"是它的简短版。她情绪低落时不主动提。

## 内容（按她需要选，不必全做）

1. **适合我的工作环境**：自主度、节奏、协作方式、环境条件、会掉电的情形。
2. **状态不好时，通常有用的恢复方式**：只用她自己说过、验证过有用的方式。
3. **我的理想一周**：能量曲线 + 她说过的舒服场景，排一个现实可行的版本。
4. **重大选择时的考虑清单**：她最看重的几个因素，以及她容易忽略的。
5. **怎么对别人说我需要什么**：把她的需求翻译成具体、不指责的话。
6. **选城市 / 选居住环境 / 选旅行方式**的筛选条件。

## 规则

- **每条建议标来源**：基于哪几条说明书条目，把握程度如何。
- 只用 ✅ 和中高把握的条目当依据；🔸推测级别只能说"可以试试看"。
- 给的是**考虑因素和选项**，不替她做重大决定。
- 不给医疗、心理治疗、投资或法律建议。涉及这些，建议她找专业人士，这份指南只覆盖偏好和生活安排。
- 建议随说明书更新，要标日期；重大选择时提醒她"人会变，这份指南每隔一段时间值得复查"。
